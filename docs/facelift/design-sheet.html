Direction A Recommended

Editorial Grotesque

A gallery wall, not a shop. Wide-set grotesque display cut against a single italic serif line, ink and bone only, brass reduced to a hairline. The scent family is the one colour permitted on the page — so colour always means something.

The call, and why.

CriterionA — Editorial GrotesqueB — Modern Classic
Distance from todayLarge. Cormorant + Lato → grotesque + one italic serif. Reads as a relaunch.Moderate. Fraunces sits in the same serif neighbourhood as Cormorant Garamond. Reads as a tidy-up.
Brief §4.3 two-colourNative. Ink and bone carry the whole page; family accent is the only colour.Works, but parchment + honey + olive is already three warm values before the accent lands.
Brief §4.6 numberingGrotesque numerals at wdth 86 give the No. 01 system real presence.Fraunces numerals are lovely but decorative; the system reads softer.
Comp adjacencyGentle Monster, Jacquemus, SSENSE. The reference set the memo actually verified.Aesop, Le Labo, Diptyque. Also credible, but the crowded lane in fragrance.
Mobile robustnessGood. Tight tracking needs a min-size floor at 30px or it crushes.Better. SOFT axis + Manrope apertures hold up at 13px without tuning.
Warmth / approachabilityCooler. Risks reading austere to a first-time fragrance buyer.Warmer. Lower bounce risk with an older or less design-literate visitor.
Font payload3 families, 2 variable. ~92 KB woff2 subset.2 families, 2 variable — but Fraunces’ 4-axis file is heavy. ~110 KB.
Build costIdentical. Same components, same token names, one variable layer swapped. Choosing is a one-file decision, not a rebuild.
Recommendation

Ship Direction A — Editorial Grotesque.

  1. It is the only one that is actually a facelift. B is a refinement of the current serif look. If the goal is that a returning visitor notices, A is the answer and B is not.
  2. It executes the brief’s hardest constraint for free. §4.3 wants two colours plus one accent, §4.4 wants no house colour in the grid, §4.5 wants black-primary / grey-secondary. Ink-and-bone gives all three by construction; the family accent is then the only colour on the page, so colour carries information instead of decoration.
  3. The numbered catalogue needs a grotesque. §4.6 is a zero-copy system upgrade — CREED AVENTUS, No. 01. Bricolage’s numerals at width 86 make that a design element. A serif makes it a footnote.
  4. It matches the comps the memo verified, not the ones it flagged as directional. Jacquemus scored 7.46 on Awwwards with a two-colour system and eased motion. That is A.

Take one thing from B: its mobile type rules. Floor A’s display at 30px and open the tracking to −0.03em below 600px, or the tight setting crushes on a 390 screen.

Pick B instead if
  • Jeff wants the store to read apothecary rather than gallery — that is a legitimate brand call, not a design error.
  • The buyer skews older than the Reddit/TikTok funnel assumes, where warmth beats austerity.
  • You want a smaller visual break while the founding-member cohort is still forming and 17 people already know the current site.

Either way the token file is the deliverable. bn-tokens.css ships Direction A as default; B is the same file with one block replaced.

Do not touch — funnel integrity

The July 16–17 incident stripped selling plans at cart store-wide. Nothing in this facelift may re-open that surface. Phase A is CSS tokens and presentational markup only: no selector renames on funnel nodes, no JS bound to add-to-cart, no magnetic behaviour on #addToCartButton. Restyle those elements by variable, never by rewriting them.
